
Python Calculator

A simple command-line calculator built with Python. It supports basic arithmetic operations along with power and square root calculations.

Features

- Addition, subtraction, multiplication, and division
- Modulus operation to find the remainder
- Power calculations
- Square root calculations
- Input validation to handle invalid entries
- Colored text output in the terminal

How to Run


1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder:
   
   cd python-calculator

3. Run the calculator:
   
   python calculator.py
